# 3DGEN releases

Download page for **3DGEN** by Mixo Creative Ltd. (明上堂有限公司): photos in, a 3D model out, on your own PC's GPU.

This repository holds release files only (the app installer and small support files). Source code is not published here.
Large components (PyTorch, model weights, Ubuntu for WSL) are downloaded by the app directly from their own providers.

- Releases: see the **Releases** section of this page.
- Licence terms ship inside each release (EULA.md, per edition). Personal edition: free, non-commercial use. Business edition: paid, commercial use.
